# 视频笔记：从保存到字幕

用户在 YouTube 或哔哩哔哩的播放页点一次「保存视频笔记到 EdgeEver」。笔记马上出现。字幕从哪来，取决于这一页当时有没有平台字幕。

只认这两类页面：YouTube 的普通视频和 Shorts，哔哩哔哩的普通视频（分 P 以地址里的 `p` 为准，没有就存第 1 P）。直播、番剧、课程和其他站点不创建笔记。

## 保存的那一刻

插件读用户正在看的这一集：标题、作者、来源、封面，以及页面里已经有的字幕。读不到这一集时提示「没有读到这个视频」，不写空笔记。

笔记先保存。用户不用等总结，也不用等后面的语音识别。桌面端没开着也一样。

保存下来的视频笔记和普通笔记不一样。在笔记列表里右键它，菜单里有「提取字幕」。普通笔记没有这一项。

## 这一页有字幕

字幕直接来自 YouTube 或哔哩哔哩，带可点回原片的时间戳，收在笔记底部的「字幕实录」里。

工作区已经配好默认聊天模型，并且剪藏用的 Token 允许调用它时，再在实录前面补三块：一句话总结、分段大纲、几条要点。有章节就用章节当大纲。模型没配、没有权限、超时或结果不可用时，总结那几块空着，实录仍然在。

保存时不下载音频。列表里仍可以再点「提取字幕」，那是再听一遍音频，新的实录接在笔记后面。

## 这一页没有字幕

笔记仍然保存：标题、作者、来源，以及一句「这一集没有可用字幕」。不调用聊天模型，也不会自己开始识别。插件到这里就结束。

要字幕时，在笔记列表右键这条笔记，选「提取字幕」。之后由已登录的桌面端接着做，仍然是同一条笔记：

1. 语音识别没开启，或本机下载工具还没准备好：笔记保持原样。这次请求留着，等以后条件齐了再试。
2. 桌面端没开：请求留到下次打开。只使用浏览器、没有桌面端的人，只能停在这句「没有可用字幕」。
3. 语音识别已开启，下载工具也就绪：桌面端下载这一集的音频，交给用户配置的语音识别接口。下载默认带上这台电脑上 Chrome 的登录状态，所以会员或需要登录的视频也能下，只要那个浏览器里已经登录。成功后，用字幕实录换掉那句「这一集没有可用字幕」。识别结果带时间戳时，时间戳可以点回原片；接口只返回全文时，笔记里就是一段文字。
4. 下载失败、识别失败、视频已知超过大约 30 分钟、音频过大，或用户已经改过这条笔记：保持保存时的内容，不会自动再试。想再试，再点一次「提取字幕」。所选浏览器没有登录，浏览器没安装，或系统不允许读取登录状态时，也是这样，笔记留在来源信息。

点过之后不再弹窗。失败不删笔记。

## 模型怎么配置

聊天模型在设置 → 模型与代理。字幕识别是左侧单独的一项，两套配置互不替代。本机 Agent 那一排不参与视频笔记。

**AI 模型服务**是原来的聊天模型。它只在「这一页有字幕」时使用，读的是字幕文本，用来写总结、大纲和要点。它不听音频。没配默认模型时，有字幕的笔记照常保存，只是没有总结。

**字幕识别**是左侧单独的一项，里面配置语音识别模型，管法和 AI 模型服务一样。可以添加多套服务。每一套有名称、兼容标准、接口地址、API Token、一个或多个模型，以及自己的启用开关。目前的兼容标准是 OpenAI，以后可以再加其他厂商。上面的默认语音模型决定提取字幕用哪一个。新添加的服务不会换掉当前默认模型。没有默认模型，或默认模型那套服务停用了，桌面端不会去下载音频。

请求发到所选服务地址下的 `/audio/transcriptions`。Token 加密存在实例上，设置页读不回原文。真正调用时，由已登录的桌面端取用，音频也从这台电脑直接发给该接口，不经过笔记服务器。

设置里可以选下载时用哪个浏览器的登录状态，网页和桌面都能看到。默认是 Chrome，也可以改成其他浏览器，或改成不使用。真正记住这个选择的是桌面端，选择只留在这台电脑上，不会上传。网页上改一项只用来查看界面。同一页也显示本机下载工具的版本和路径；浏览器里没有这个工具时，版本显示尚未下载。

接口要兼容 OpenAI 的语音转写：用 Bearer Token，提交音频文件和模型 ID。聊天模型的地址不能填在这里。
